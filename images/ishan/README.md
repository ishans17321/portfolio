# About page photos

Drop photos into this folder using these exact names and the About page will pick them up automatically:

- `portrait.jpg` — a photo of Ishan for the top of the page
- `rc-plane.jpg` — a plane or flying-field photo
- `drone-build.jpg` — a drone build or finished drone
- `engineering-cs.jpg` — a workshop, electronics, or coding photo
- `san-diego.jpg` — a favorite San Diego photo

Landscape photos work best for the project sections. The portrait can be vertical. JPG, JPEG, PNG, and WebP files all work, but update the matching path in `navigation/about.md` if the extension or filename changes.
