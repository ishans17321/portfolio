The interactive build above and the examples below use the same ordered parts list, correctness check, attempt history, and accuracy calculation. Open a section and copy it directly into the matching runner.

Input + output

The player chooses a part and a target; the interface displays accepted or rejected feedback.

List

parts stores the required order and attempts stores each true/false result.

Procedure

checkPlacement(part, target) accepts two parameters and returns a Boolean value.

Selection

IF/ELSE decides whether the part stays installed or returns to the tray.

Iteration

A loop processes the attempt list to calculate the player's accuracy.

Sequence

Read input, check the fit, record the attempt, update the step, and display feedback.

Boolean logic

A placement passes only when the target is correct AND the part is next in order.

Complete algorithm

All concepts work together to solve the meaningful problem of assembling a PC correctly.

PSPseudocodePaste into the College Board pseudocode runner
pc_assembly.pseudo
parts ← ["CPU", "RAM", "SSD", "CPU cooler", "Power supply", "Motherboard", "Graphics card", "Power cables"]
targets ← ["CPU socket", "RAM slots", "M.2 slot", "Cooler mount", "PSU bay", "Board tray", "PCIe slot", "Power headers"]
attempts ← []
currentStep ← 1

PROCEDURE checkPlacement(partName, targetName)
{
  correctPart ← (partName = parts[currentStep])
  correctTarget ← (targetName = targets[currentStep])

  IF (correctPart AND correctTarget)
  {
    RETURN(true)
  }
  ELSE
  {
    RETURN(false)
  }
}

REPEAT UNTIL (currentStep > LENGTH(parts))
{
  DISPLAY("Next part: " + parts[currentStep])
  selectedPart ← INPUT("Choose a PC part:")
  selectedTarget ← INPUT("Choose its destination:")
  isCorrect ← checkPlacement(selectedPart, selectedTarget)
  APPEND(attempts, isCorrect)

  IF (isCorrect)
  {
    DISPLAY(selectedPart + " snapped into place!")
    currentStep ← currentStep + 1
  }
  ELSE
  {
    DISPLAY("Incorrect placement. The part returned to the tray.")
  }
}

correctAttempts ← 0
FOR EACH result IN attempts
{
  IF (result = true)
  {
    correctAttempts ← correctAttempts + 1
  }
}

accuracy ← (correctAttempts / LENGTH(attempts)) * 100
DISPLAY("PC assembly complete!")
DISPLAY("Accuracy: " + accuracy + "%")

<script>
const parts = ["CPU", "RAM", "SSD", "CPU cooler", "Power supply", "Motherboard", "Graphics card", "Power cables"];
const targets = ["CPU socket", "RAM slots", "M.2 slot", "Cooler mount", "PSU bay", "Board tray", "PCIe slot", "Power headers"];
const attempts = [];
let currentStep = 0;

const partInput = document.getElementById("partInput");
const targetInput = document.getElementById("targetInput");
const output = document.getElementById("output");

for (const part of parts) {
  partInput.add(new Option(part, part));
}

for (const target of targets) {
  targetInput.add(new Option(target, target));
}

function checkPlacement(partName, targetName) {
  const correctPart = partName === parts[currentStep];
  const correctTarget = targetName === targets[currentStep];
  return correctPart && correctTarget;
}

function calculateAccuracy(results) {
  let correctAttempts = 0;
  for (const result of results) {
    if (result === true) {
      correctAttempts += 1;
    }
  }
  return Math.round((correctAttempts / results.length) * 100);
}

document.getElementById("placeButton").addEventListener("click", function () {
  const selectedPart = partInput.value;
  const selectedTarget = targetInput.value;
  const isCorrect = checkPlacement(selectedPart, selectedTarget);
  attempts.push(isCorrect);

  if (isCorrect) {
    currentStep += 1;
    if (currentStep === parts.length) {
      output.textContent = `PC complete! Accuracy: ${calculateAccuracy(attempts)}%`;
      this.disabled = true;
    } else {
      output.textContent = `${selectedPart} installed. Next: ${parts[currentStep]}`;
    }
  } else {
    output.textContent = `Incorrect. Install ${parts[currentStep]} in the ${targets[currentStep]}.`;
  }
});
</script>
PYPythonPaste into the Python runner and enter text when prompted
pc_assembly.py
parts = ["CPU", "RAM", "SSD", "CPU cooler", "Power supply", "Motherboard", "Graphics card", "Power cables"]
targets = ["CPU socket", "RAM slots", "M.2 slot", "Cooler mount", "PSU bay", "Board tray", "PCIe slot", "Power headers"]
attempts = []
current_step = 0

def check_placement(part_name, target_name):
    correct_part = part_name.lower() == parts[current_step].lower()
    correct_target = target_name.lower() == targets[current_step].lower()
    return correct_part and correct_target

while current_step < len(parts):
    print("\nNext part:", parts[current_step])
    selected_part = input("Choose a PC part: ").strip()
    selected_target = input("Choose its destination: ").strip()
    is_correct = check_placement(selected_part, selected_target)
    attempts.append(is_correct)

    if is_correct:
        print(selected_part, "snapped into place!")
        current_step += 1
    else:
        print("Incorrect placement. The part returned to the tray.")
        print("Hint:", parts[current_step], "goes in", targets[current_step])

correct_attempts = 0
for result in attempts:
    if result:
        correct_attempts += 1

accuracy = round((correct_attempts / len(attempts)) * 100)
print("\nPC assembly complete!")
print("Accuracy:", str(accuracy) + "%")

Language reflection

JavaScript felt most natural for this project because it connects directly to HTML buttons, drag-and-drop events, and visible browser feedback. Python made the algorithm shorter and easier to read, but its terminal input could not create the same snap-in experience without an additional graphics library. Pseudocode was the clearest way to plan the logic because it focused on sequence, selection, iteration, and lists without language-specific syntax.
