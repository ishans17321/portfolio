## Submission checklist

All code cells were executed independently so each works in an individual runner. Recorded outputs are shown below the editors; rerunning an editor produces fresh results. MCQ answer keys include explanations for each answer.

Fictional student responses, roster names, measurements, and season records are labeled. The Peppa Maze and Developing Procedures pages assign practice rather than a separate homework rubric; their practice is included.

For code submission, copy the final homework cell without Markdown fences. For file submission, use the notebook download. Publish the portfolio, open each required URL, then submit it through the corresponding lesson form. Live classroom participation, peer playtests, and submission confirmations still require the student; this portfolio does not claim they happened.
