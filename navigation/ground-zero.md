# Ground Zero: What the lessons have covered so far

This page is a starting map of the computer science ideas represented in my portfolio. It gathers the Python homework, AP CSP practice, and Create Performance Task concept lessons in one place. It is a review guide, not a claim that every course topic or skill has been mastered.

## The core idea

A program takes input, stores and transforms information, makes decisions, repeats steps when needed, and produces output. Procedures package work so it can be called again. Testing checks whether the program behaves as expected for ordinary and unusual inputs. A good explanation connects the code to its purpose and evidence.

## A repeatable way to work through a problem

1. **Understand the task:** identify the input, expected output, and constraints.
2. **Plan:** write the steps in plain language or pseudocode and choose suitable data.
3. **Trace:** use a small example to follow assignments, conditions, loops, and procedure calls.
4. **Implement:** translate the plan into code and keep each part readable.
5. **Test:** check a typical case, a boundary case, and an unusual or empty case.
6. **Explain and improve:** describe why the result follows, fix errors, and retest.
